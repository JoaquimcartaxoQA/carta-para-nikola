# carta-para-nikola
Jogo de corrida 2D infantil

## Abordagem de QA

Os testes de regressão verificam regras de física e classificação. No Chromium, Playwright valida as três pistas, teclado, toque e transições de estado como pausa, retomada e pódio. A cobertura do código executado no navegador é registrada separadamente da cobertura dos testes Node. [Regressões e resultados no PR #4](https://github.com/JoaquimcartaxoQA/carta-para-nikola/pull/4)
